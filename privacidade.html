Política de privacidade

Atualizada em 26 de outubro de 2026

Quem somos

O mapp é um aplicativo pessoal para Windows, mantido por Victor de Oliveira para uso próprio. Não há empresa, servidor ou serviço on-line do mapp por trás dele.

Onde ficam os dados

Tudo o que o mapp lê ou calcula fica guardado no computador do usuário, numa pasta local. Tokens de acesso e senhas ficam criptografados pelo próprio Windows. O mapp não envia esses dados ao desenvolvedor nem a terceiros, não vende dados, não exibe anúncios e não faz rastreamento.

Dados do Google que o mapp acessa

Só com a autorização do usuário, pela tela de login do Google, e só para as funções abaixo:

  • Gmail (somente leitura): procura e-mails de bancos e contas para importar faturas, extratos e boletos e para mostrar alertas ao próprio usuário. O mapp nunca envia, apaga ou altera e-mails.
  • Google Agenda: mostra os próximos eventos e cria um evento só quando o usuário confirma na tela. O mapp não altera nem apaga eventos.
  • Google Drive (pasta privada do app): se o usuário ligar a opção, guarda um resumo do mês cifrado (AES-256), que só os aparelhos do próprio usuário conseguem abrir. O mapp não vê nenhum outro arquivo do Drive.
  • Nome, e-mail e foto da conta: para mostrar quem está conectado.

Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados do Google não são usados para publicidade nem para treinar modelos de inteligência artificial.

Se o usuário ligar a assistente do app (R2D2, com a chave de API do próprio usuário), o remetente, o assunto e um trecho dos e-mails, e os eventos da agenda, são enviados à API da Anthropic só quando ele pede um resumo ou faz uma pergunta, e só para responder a esse pedido. Sem a assistente ligada, nada disso sai do computador.

Como remover o acesso

O usuário pode desconectar o Google no próprio mapp (Ajustes › Gmail) ou revogar o acesso a qualquer momento em myaccount.google.com/permissions. Apagar a pasta de dados do mapp no computador remove tudo o que ele guardou.
